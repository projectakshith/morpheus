# UI/UX Design Skill

## Visual Hierarchy & Polish
1. **Typography & Contrast**: Clear contrast ratios (WCAG AA compliant). Hierarchy: Page Title > Section Header > Body > Caption/Muted.
2. **Spacing Consistency**: Strict multiples of 4px/8px (e.g., Tailwind `p-2`, `p-4`, `gap-6`). Never use arbitrary ad-hoc margins.
3. **Interactive States**: Every interactive element needs distinct default, hover, active, focus-visible, and disabled states.
4. **Mobile & Responsive**: Mobile-first layout thinking; ensure touch targets are at least 44x44px.
