# Output Style & Readability

1. **Divider Lines**: Use `---` dividers between major sections to make terminal output effortless to scan.
2. **Clear Headers**: Use short markdown headers (e.g. `### what changed`, `### key files`, `### verification`).
3. **High Density**: Favor crisp bullet points, exact code symbols, and backticked file paths over long paragraphs.
4. **Tables**: Use markdown tables when comparing options, showing metrics, or presenting structured lists.
5. **Brevity**: Start with a 1-line summary of what was accomplished, then deliver the breakdown. Zero corporate fluff.
